01 · The problem

On average, Depth Anything V2 Small gets 97.3% of NYU pixels within 25% of their true depth. That number hides where the other pixels go wrong. They gather into regions, and a region can have a cause you can name, measure and test.

1AlignFit the prediction to the sensor in disparity space, per image
2FindGroup pixels failing δ1 on measured depth into regions
3MeasureGradient, depth edges, thin structure, sensor holes, brightness
4LabelName a likely cause, or abstain when evidence is weak
5TestEdit the image, re-run the model, compare with matched controls

04 · Labels

Six names for a failure, graded honestly

Four labels are small logistic models fitted on NYU train. Each is scored against object annotations, where 0.5 is chance. Hypersim and iBims-1 were never seen while fitting, so they are the clean checks. NYU test shaped this version of the labels, so it is not confirmatory.

05 · Put to the test

Edit the image. Re-run the model.

If a label names the real cause, fixing that cause should help labelled regions more than matched controls. Each test uses 120 pairs given the same edit. Left of zero means the edit helped labelled regions more.

ρ = −0.26
Specular light does raise depth error. Removing it from synthetic Hypersim renders, the more specular light a region had, the more its error fell. Spearman ρ = −0.26, 95% CI [−0.36, −0.14].

06 · Eight models

The leaderboard, on three datasets

All models are evaluated after per-image alignment. Switch the metric and watch the order change.

* Trained on NYU, so its NYU row is not a fair comparison. † Diffusion model run with 4 denoising steps and no ensembling, lighter than in its paper. DIODE: 325 indoor frames. iBims-1: 100 indoor images keeping transparent surfaces, so not comparable with published numbers.

Size matters

Larger Depth Anything models reliably reduce AbsRel on NYU and iBims-1. On DIODE, neither step up in size reliably changes it.

Hybrid vs. pure ViT

No reliable difference on any outcome between DPT-Hybrid and DPT-Large, on any of the three datasets.

Diffusion

Depth Anything V2 Small has lower AbsRel than Marigold on NYU and DIODE, with no reliable difference on iBims-1.

Family

DPT-Hybrid fails on about three times as many pixels as Depth Anything V2 Small, largely in regions labelled textureless. Training data differs too, so this is not attributed to architecture.

07 · What didn't hold up

Two claims, tested and cut

Both rules were written before the results were scored.

Cut

A ViT vs. CNN failure “fingerprint”

A label counts only if its share of a model's failing regions differs reliably, in the same direction, on NYU, DIODE and iBims-1.

  • DPT-Hybrid vs. DPT-Largeno label passes
  • DA-V2 Small vs. DPT-Hybridonly textureless

Textureless share, DA-V2 Small minus DPT-Hybrid. That label is close to chance against annotations, so this is a difference in VEO's labels, not an established difference in failure type.

Not supported

Using the diagnosis to fine-tune

Fine-tuning the decoder on NYU train while up-weighting the regions VEO diagnosed made those targets worse, in all three seeds.

AbsRel on annotated pixels. Plain fine-tuning with no weighting improved overall AbsRel from 0.051 to 0.046. The weighting did act on its training regions (0.31 → 0.17 at seed 0), so it fitted those regions instead of learning anything general. One weighting strength, one dataset.

09 · Limits

Read this before you cite it

Annotations are a proxy. Wall and ceiling stand in for “textureless”, and on average 42% of a region's pixels on NYU have no annotation at all.
Labels describe more than they explain. Only one of four image-edit tests supported its label, and that one is exploratory.
The audit needs ground truth. Finding failure regions and two of the label cues rely on measured depth.
Some failures may be sensor errors. On reflective surfaces, predictions tend to be nearer than the sensor's reading, which may mean the sensor is wrong.
DIODE labels can't be checked. It has no annotations, and its tests use 10 scans from 3 scenes, which are not independent.
Indoor only. The labels were fitted on indoor data. Outdoor scenes are not covered, and the human study still needs raters.

10 · Run it

Audit your own depth model

Save one .npy prediction per image, point a config at your data, and VEO does the rest. The whole pipeline also runs on a small synthetic fixture with no downloads or GPU.

View on GitHub ↗ Protocols
bash
# clone and test
git clone https://github.com/MdZeeshanAli01/VEO_V2.git
cd VEO_V2 && uv sync --extra dev
uv run python -m pytest -q

# the whole pipeline, no GPU needed
uv run python -m veo.cli reproduce --fixture --workdir /tmp/veo

# audit your own predictions
uv run python -m veo.cli run-precomputed \
  --config my_config.yaml \
  --prediction-dir my_predictions \
  --output-dir outputs/my_model
